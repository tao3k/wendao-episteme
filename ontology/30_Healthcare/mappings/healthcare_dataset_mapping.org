This source contract maps de-identified synthetic healthcare rows into
Healthcare ontology observations. The raw tables are not ontology truth. RDF
classes and object properties remain the semantic authority, and DuckDB SQL
materializes reviewable object, link, and evidence observations.

** Raw table coverage

| source_table | required_columns | ontology_role |
| raw_patients | patient_id, patient_name, birth_year, source_system | Patient object observations |
| raw_providers | provider_id, provider_name, provider_kind, source_system | CareProvider object observations |
| raw_encounters | encounter_id, patient_id, provider_id, encounter_label, encounter_date, source_system | Encounter object observations and patient/provider links |
| raw_conditions | condition_id, patient_id, condition_name, recorded_date, source_system | MedicalCondition object observations and diagnosis links |

** Object mappings

| source_table | source_key | ontology_object_type | rdf_class | display_name |

** Mapping evidence

| evidence_id | source_table | source_key | review_state | decision |
| evidence:raw_patients:P001 | raw_patients | P001 | accepted | Patient object mapping uses patient_id as stable source key |
| evidence:raw_encounters:E001 | raw_encounters | E001 | accepted | Encounter links must include patient and provider context |
| evidence:raw_conditions:C001 | raw_conditions | C001 | accepted | Condition rows instantiate MedicalCondition observations |

** Rejected ambiguities

| ambiguity | decision |
| provider_kind_as_class | Rejected for this slice; provider_kind remains source evidence, not an RDF subclass. |
| birth_year_as_identity | Rejected for identity; patient_id remains the primary source key. |
| encounter_date_as_temporal_ontology | Deferred until lifespan/validity mapping is introduced. |
